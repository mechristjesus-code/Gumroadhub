Installation Guide

For Desktop/Laptop:

  1. Install Ollama: https://ollama.ai
  2. Run: ollama pull tinyllama
  3. Start: ollama serve

For Termux (Android Phone):

  1. Install Ollama in Termux: pkg install ollama
  2. Pull model: ollama pull tinyllama
  3. Start: ollama serve --host 0.0.0.0
  4. Access from browser: http://localhost:11434

Model Information:

TinyLlama (1.1B) - Optimized for phones and low-resource devices

  • Size: ~600MB
  • Memory: ~2GB RAM required
  • Speed: Fast inference on mobile
  • Quality: Good for product descriptions, suggestions, basic analysis
